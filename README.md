# CloudFlux

## Vision

CloudFlux is a long-term cloud engineering portfolio project.

The goal is to build a modern SaaS platform that demonstrates professional software engineering practices, cloud architecture, DevOps, AI integration, security, and scalable infrastructure.

This project is built as a learning journey and will evolve through multiple milestones rather than being developed all at once.

## Goals

- Learn professional software engineering
- Learn backend development
- Learn frontend development
- Learn databases
- Learn Docker
- Learn Kubernetes
- Learn Terraform
- Learn CI/CD
- Learn AWS cloud architecture
- Learn testing
- Learn system design

## Principles

- Clean Architecture
- Scalability
- Security First
- Maintainability
- Documentation
- Test Driven where practical
